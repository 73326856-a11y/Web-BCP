# Banca Personas — Demo web (GitHub Pages)

Sitio estático inspirado en un mockup de banca personal (cuentas, tarjetas, hipotecario, vehicular, préstamos, inversiones y seguros).

> **Aviso:** este proyecto es una demostración educativa / de portafolio. **No es un sitio oficial** de Banco de Crédito del Perú ni de Credicorp. No procesa dinero, no abre cuentas reales y no solicita credenciales de banca.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube esta carpeta.
2. En el repositorio: **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main` (o `master`) y carpeta `/ (root)`.
5. Abre la URL `https://tu-usuario.github.io/nombre-del-repo/`.

Si el repositorio se llama `tu-usuario.github.io`, el sitio queda en la raíz de tu dominio Pages.

## Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Sin build, sin Node y sin backend — listo para GitHub Pages

## Páginas

- `index.html` — inicio
- `ahorros.html` — cuentas de ahorro y simulador
- `tarjetas.html` — débito / crédito y solicitud
- `hipotecario.html` — vivienda
- `vehicular.html` — crédito vehicular
- `prestamo.html` — préstamo personal
- `inversiones.html` — fondos y depósito a plazo
- `seguros.html` — protecciones
- `pymes.html` — herramientas para emprendedores
- `cobros.html` — Izipay vs Culqi
- `empresas.html` — banca corporativa
